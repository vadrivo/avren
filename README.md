# AVREN — Modern Essentials

Premium frontend-only fashion e-commerce showcase built with React, Vite and TypeScript.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

Vite is configured with:

`base: "/avren/"`

Deploy the `dist` output using GitHub Pages / GitHub Actions.

The application uses browser state and localStorage for cart and wishlist persistence. No backend or real payment processing is included.
